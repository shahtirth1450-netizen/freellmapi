Step-by-Step Walkthrough

Connect Claude Code to FreeLLMAPI in 4 steps

Run FreeLLMAPI locally, add your free-tier keys, wire Claude Code with a single command (no config guesswork), and optionally enable prompt compression to fit more turns inside small-context free models.

01

Install & Start FreeLLMAPI

Use the Desktop app (v0.16.44) on port 31415 or self-host via Node.js / Docker on port 3001.

Windows .exe / .zip macOS .dmg (arm64/x64) Linux .AppImage / .deb 
git clone https://github.com/shahtirth1450-netizen/freellmapi.git
cd freellmapi
npm install
npm run dev
git clone https://github.com/shahtirth1450-netizen/freellmapi.git
cd freellmapi
cp .env.example .env
docker compose up -d
02

Add Free Provider Keys & Copy Unified Key

Open the dashboard (http://127.0.0.1:31415 for Desktop or http://localhost:3001 for server), open the Keys page, add free-tier keys (Groq, Google Gemini, Cerebras, OpenRouter, NVIDIA, Mistral, etc.), and copy your single freellmapi-… key.

Important URL rule: Claude Code speaks Anthropic Messages, so pass the bare origin without /v1 (http://127.0.0.1:31415 or http://localhost:3001). 
# Optional CLI key management (requires dashboard session token):
export FREELLMAPI_URL=http://localhost:3001
export FREELLMAPI_DASHBOARD_TOKEN="<dashboard-session-token>"
npx freellmapi keys add groq
npx freellmapi keys list
03

Connect & Launch Claude Code

Use npx freellmapi launch to inject credentials per run without writing secrets to disk, or run setup-claude to write ~/.claude/settings.json (with CLAUDE_CODE_AUTO_MODE_SERVER=0 set automatically). 

# Server (:3001) — use http://127.0.0.1:31415 for Desktop app
npx freellmapi launch --url http://localhost:3001 --api-key <unified-key>
npx freellmapi setup-claude --url http://localhost:3001 --api-key <unified-key> --dry-run
npx freellmapi setup-claude --url http://localhost:3001 --api-key <unified-key>
$env:ANTHROPIC_BASE_URL = "http://127.0.0.1:31415"
$env:ANTHROPIC_AUTH_TOKEN = "<unified-key>"
$env:CLAUDE_CODE_AUTO_MODE_SERVER = "0"
claude
export ANTHROPIC_BASE_URL="http://localhost:3001"
export ANTHROPIC_AUTH_TOKEN="<unified-key>"
export CLAUDE_CODE_AUTO_MODE_SERVER="0"
claude
04

Verify Routing & Enable Prompt Compression

Verify Claude Code traffic reaches the gateway with doctor, and optionally turn on Prompt Compression (off by default) under Settings → Prompt compression to compact repeated system prompts and tool outputs. 

# Verify Claude Code reaches your local FreeLLMAPI gateway:
npx freellmapi doctor claude --url http://localhost:3001 --api-key <unified-key>

# Or enable lossless/standard compression at startup in .env:
FREELLMAPI_COMPRESSION=lossless

Want Codex CLI, Cursor, Cline, OpenCode, or Gemini CLI too? Run npx freellmapi list to view all supported agents.

Capabilities

Everything behind one unified API

Built for coding agents, local apps, and multi-provider reliability.

OpenAI-Compatible Surfaces

Supports /v1/chat/completions, /v1/responses, /v1/completions, /v1/embeddings, /v1/images/generations, /v1/audio/speech, and /v1/audio/transcriptions.

Anthropic, Gemini & Ollama

Speaks /v1/messages for Claude Code, /v1beta for Gemini CLI, and opt-in Ollama endpoints for Zed and JetBrains.

Smart Routing & Failover

Six routing presets (auto, auto:fast, auto:smart, named fallback chains) with cooldowns and key rotation on 429/5xx.

Fusion Synthesis

Target the virtual fusion model to query diverse models in parallel and synthesize one response.

AES-256-GCM Encrypted Keys

Provider credentials stay encrypted at rest in SQLite; apps only ever see your single unified freellmapi-… key.

Coding Agent CLI & MCP

Configure Claude Code, Codex, Cursor, Cline, OpenCode, and more with npx freellmapi, plus an integrated /mcp server.

How It Works
