Features

Everything behind one unified API

Built for coding agents, local apps, and multi-provider reliability.

OpenAI-Compatible Surfaces

Supports /v1/chat/completions, /v1/responses, /v1/completions, /v1/embeddings, /v1/images/generations, /v1/audio/speech, and /v1/audio/transcriptions.

Anthropic, Gemini & Ollama

Speaks /v1/messages for Claude Code, /v1beta for Gemini CLI, and opt-in Ollama endpoints for Zed and JetBrains.

Smart Routing & Failover

Six routing presets (auto, auto:fast, auto:smart, named fallback chains) with cooldowns and key rotation on 429/5xx.

Fusion Synthesis

Target the virtual fusion model to query diverse models in parallel and synthesize one response.

AES-256-GCM Encrypted Keys

Provider credentials stay encrypted at rest in SQLite; apps only ever see your single unified freellmapi-… key.

Coding Agent CLI & MCP

Configure Claude Code, Codex, Cursor, Cline, OpenCode, and more with npx freellmapi, plus an integrated /mcp server.

Quick Start

Run locally in minutes

Clone from shahtirth1450-netizen/freellmapi, start the server, and point any SDK or coding agent at localhost:3001.

git clone https://github.com/shahtirth1450-netizen/freellmapi.git
cd freellmapi
npm install
npm run dev
git clone https://github.com/shahtirth1450-netizen/freellmapi.git
cd freellmapi
cp .env.example .env
docker compose up -d
npx freellmapi setup-claude --url http://localhost:3001 --api-key <unified-key>
npx freellmapi setup-codex  --url http://localhost:3001 --api-key <unified-key>
npx freellmapi list
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:3001/v1",
    api_key="freellmapi-your-unified-key",
)

response = client.chat.completions.create(
    model="auto",
    messages=[{"role": "user", "content": "Summarise the fall of Rome in one sentence."}],
)
print(response.choices[0].message.content)
How It Works

Routing, Key Vault & Playground

Fallback Chain

Selects the highest-ranked healthy key under RPM/RPD/TPM/TPD limits and cools down 429s automatically.

Encrypted Key Vault

Manage provider keys and custom OpenAI-compatible endpoints with live health status checks.

Built-in Playground

Test prompts, images, and streaming responses while seeing exactly which provider served each turn.
